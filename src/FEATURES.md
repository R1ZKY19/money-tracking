# FinCat - Fitur-Fitur Lengkap

Personal Financial Management Dashboard untuk melacak transaksi, hutang, tabungan, dan aset Anda.

## 📊 Dashboard & Analisis

### Monthly Dashboard
Pantau ringkasan keuangan bulanan dengan KPI, grafik tren, dan insight otomatis tentang kesehatan finansial Anda.

### Yearly Dashboard
Analisis rinci per bulan selama setahun penuh dengan perbandingan kategori pendapatan dan pengeluaran.

### Year-over-Year Comparison
Bandingkan pendapatan dan pengeluaran tahun ini vs tahun lalu dengan grafik garis bulanan dan perhitungan growth rate.

### Net Worth Tracker
Pantau total aset, liabilitas, dan nilai kekayaan bersih Anda di berbagai mata uang dengan visualisasi pie chart.

## 💳 Manajemen Transaksi

### Input Transaksi
Catat transaksi manual dengan dukungan kategori, akun, dan berbagai tipe transaksi (income, expense, transfer, debt payment, receivable receipt).

### Riwayat Transaksi
Lihat daftar lengkap semua transaksi dengan filter berdasarkan periode, kategori, tipe, dan search.

### Transfer Akun
Transfer uang antar akun Anda dengan pembaruan saldo otomatis dan pencatatan transaksi.

### Auto-Categorize
Saat import transaksi, sistem memberikan saran kategori otomatis berdasarkan deskripsi transaksi.

### Data Backup & Export
Ekspor semua data finansial Anda (akun, transaksi, hutang, tabungan, dll) ke file JSON untuk backup aman dan restore data.

## 🎯 Perencanaan & Target

### Budget Plan
Rencanakan budget bulanan dengan detail target pendapatan, pengeluaran, dan tabungan per kategori.

### Expense Goal
Tetapkan target pengeluaran maksimal per kategori dengan alert otomatis saat mendekati atau melampaui target. Monitoring real-time progress dengan progress bar.

### Target Tabungan (Saving Goals)
Buat target penghematan dengan deadline, pantau progress, dan kelola beberapa tujuan finansial sekaligus.

### Saldo Akun
Kelola akun bank/e-wallet Anda dengan pilihan bank konvensional, logo bank otomatis, dan pemantauan saldo real-time.

## 💰 Keuangan & Hutang

### Hutang (Debt)
Catat hutang dengan bunga, deadline, dan kelola pembayaran cicilan untuk melacak sisa saldo. Support multiple currencies.

### Piutang (Receivable)
Catat uang yang dipinjamkan ke orang lain dengan bunga bulanan otomatis dan terima pembayaran cicilan. Histori pembayaran lengkap per piutang.

### Email Reminder
Terima notifikasi email otomatis setiap hari pada pukul 09:00 untuk hutang yang jatuh tempo atau akan jatuh tempo minggu depan. Reminder mencakup detail kreditor dan jumlah hutang.

## 🌍 Fitur Tambahan

### Multi-Bahasa
Dukungan penuh untuk Indonesia dan English. Ganti bahasa dengan tombol globe di sidebar.

### Dark Mode
Tekan tombol moon/sun di sidebar untuk beralih antara tema light dan dark.

### Activity Log
Catat semua aktivitas pengguna untuk keperluan audit dan keamanan.

### Responsive Design
Aplikasi fully responsive untuk desktop, tablet, dan mobile.

## 🚀 Tips Penggunaan

1. **Setup Awal**: Buat akun bank/e-wallet Anda terlebih dahulu di menu Saldo Akun sebelum mencatat transaksi.

2. **Kategori**: Sesuaikan kategori pendapatan dan pengeluaran di menu Pengaturan untuk kebutuhan Anda.

3. **Budget Planning**: Set budget bulanan di Budget Plan untuk kontrol pengeluaran yang lebih baik.

4. **Monitoring Hutang**: Aktifkan Email Reminder untuk mendapatkan notifikasi hutang yang akan jatuh tempo.

5. **Export Data**: Secara berkala export data Anda menggunakan fitur Data Backup & Export untuk backup aman.

6. **Multi-Currency**: Gunakan Net Worth Tracker untuk monitoring aset di berbagai mata uang.
